# Flutter AirRun

Flutter AirRun permet de connecter, associer et utiliser un téléphone Android avec Flutter sans câble USB directement depuis Visual Studio Code.

## Fonctionnalités

- Détection des appareils Android
- Vérification de Flutter, Android SDK et ADB
- Association avec un code
- Association sécurisée avec un QR code
- Connexion automatique au débogage sans fil
- Lancement de `flutter run`
- Hot reload et hot restart
- Barre latérale Flutter AirRun

## Utilisation

Ouvrez la vue **Flutter AirRun** dans la barre d’activité de Visual Studio Code, puis choisissez une action :

- Lancer l’application sans fil
- Associer un téléphone par QR code
- Associer un téléphone avec un code
- Vérifier l’environnement
- Afficher les appareils
- Vérifier la connexion sans fil

## Prérequis

- Flutter
- Android SDK
- ADB
- Android 11 ou version ultérieure pour le débogage sans fil
- Ordinateur et téléphone connectés au même réseau local

## Plateforme supportée par cette version

Cette première distribution contient un helper natif pour :

- Linux x86-64

Les paquets Windows, macOS et Linux ARM seront ajoutés séparément.
