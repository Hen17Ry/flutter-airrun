# Changelog

## 0.1.0

Première version fonctionnelle de Flutter AirRun.

### Ajouts

- Diagnostic de l’environnement Flutter et Android
- Détection des appareils ADB
- Vérification du débogage sans fil
- Association Android avec un code
- Association Android avec un QR code
- Helper natif sécurisé
- Récupération automatique du port ADB
- Lancement Flutter sans fil
- Hot reload et hot restart
- Vue Flutter AirRun dans la barre d’activité
- CLI Flutter AirRun interactive
